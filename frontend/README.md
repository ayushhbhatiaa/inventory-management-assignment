# InventoryFlow

Office Inventory Management System

# Tech Stack

- React
- Spring Boot
- H2 Database
- JWT Authentication

Run Backend

mvn spring-boot:run

Runs on

http://localhost:8081

Run Frontend

npm install
npm run dev

Runs on

http://localhost:5173
