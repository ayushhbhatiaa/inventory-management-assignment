# InventoryFlow Frontend

React application for InventoryFlow.

---

## Tech Stack

- React 19
- Vite
- React Router
- Axios
- Bootstrap

---

## Install

```bash
npm install
```

---

## Run

```bash
npm run dev
```

Runs on

```
http://localhost:5173
```

---

## Features

- JWT Login
- Dashboard
- Products
- Employees
- Inventory Requests
- Protected Routes
- Axios API Integration
- Bootstrap UI
